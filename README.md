# yq 平台 · 教育平台一体化教务管理系统

> yq 平台是一套面向学校的**业务管理与教务教学一体化管理系统**，覆盖「招生报名 → 排课教学 → 在线考试 → 订单支付 → 财务结算」全流程，帮助机构把依赖人工表格的运营方式升级为线上化、数字化、可追溯的平台运营。

---

## 一、平台简介

传统培训机构在排课、报名、考试等环节高度依赖 Excel 和人工协作：课表靠手工排、学员报名重复录入、考试需要线下收发卷、教师授课时间经常冲突。yq 平台针对这些高频业务痛点，提供一套「管理端 + 学生端」双端联动的解决方案：

- **管理端（/emp）**：面向机构运营、教务、财务与讲师，统一管理用户权限、班级排课、课程内容、教师分配、订单与考试。
- **学生端（/stu）**：面向学员，提供登录报名、在线查看课表、按课程进度学习、在线作答考试等能力。

平台通过一套 RBAC 权限体系把不同角色（管理员、讲师、运营、学生）的操作边界清晰隔离开，让权限、数据、流程都能按角色闭环运转。

## 二、目标用户与业务场景

| 角色 | 关注点 | 典型场景 |
| --- | --- | --- |
| 机构负责人 / 管理员 | 全局掌控、授权管理 | 账号角色分配、平台运营数据查看、权限统一管控 |
| 教务 / 排课人员 | 排课效率、规避冲突 | 批量导入课程详情、自动生成班级课表、分配授课教师 |
| 销售人员 | 报名转化、订单状态 | 生成预定单、跟踪缴费进度、学员状态流转 |
| 讲师 | 教学、命题、批改 | 上传作业标准、维护题库与组卷、在线批改主观题 |
| 学员 | 学习、缴费、应考 | 在线报名缴费、查看个人课表、参加线上考试 |

## 三、核心业务模块

### 1. 用户与权限管理（RBAC）
- 采用五张表（用户、角色、权限、用户角色、角色权限）构建完整权限模型。
- 内置 `ADMIN / LECTURER / STUDENT / OPERATOR` 四个固定角色，启动时自动初始化。
- 接口通过 `@HasPermission` 注解声明所需权限，应用启动时**自动将接口权限同步到数据库**，管理员授权后即可生效，无需人工维护权限清单。

### 2. 学员管理与报名
- 销售确认意向后生成**预定单**，同步创建「临时学员」账号。
- 学员凭账号在学生端登录、在线缴费，支付成功后自动升级为「在校」状态，订单同步置为已支付。
- 学员状态随报班、缴费、转班等动作流转，全过程可追溯。

### 3. 课程与课程详情管理
- 支持课程、课程阶段、逐日课程详情的结构化维护。
- 面向线下长周期课程，提供 **Excel 批量导入课程详情** 能力，一次录入几十天的课程内容，逐行校验、分批入库，告别逐条手填。

### 4. 班级排课（课表自动生成）
- 选定班级与开课日期即可**自动生成课表**。
- 内置排课规则引擎：自动规避法定节假日、固定自习日与休息日，严格对齐「课程 → 阶段 → 每日内容」的数据结构，保证每天课程内容完整、可上课。

### 5. 教师按阶段排课（防冲突）
- 按课程阶段为班级分配授课教师，核心约束是**一个教师不会同时出现在两门课中**。
- 分配时自动检索该时段已排课教师，从候选集中排除，避免教师档期冲突。

### 6. 临时课程
- 支持在既有课表中插入临时课程；当插入日已为上课日时，自动联动重排该日之后的课程序列，保证课表连续不遗漏。

### 7. 订单与支付
- 对接**支付宝**（RSA2 验签），服务端生成支付流水、前端完成收银台支付、回调异步更新订单与学员状态，支付完成后可回跳到用户端首页。

### 8. 考试管理
- **题库**：单选/多选/填空/简答等题型，可按课程、阶段、难度、状态组合维护。
- **组卷**：手动组卷，支持从题库按阶段/难度/题型筛选选入，设置分值顺序，总分由后端核算。
- **考试发布**：按班级批量发布考试，设定开放时间、入场截止、考试时长与监考人。
- **学生考试**：学生端在线作答、逐题自动保存、断线续答；提交或超时自动封卷。
- **自动交卷**：基于 RocketMQ 延时消息 + 定时补偿任务，保证超时自动交卷不丢失、不重复。
- **批改与公布**：客观题自动判分，主观题人工批改；成绩与答卷按设置开关在考试结束后统一公布。

### 9. 文件管理（作业与资料）
- 对接**阿里云 OSS 预签名上传**，区分「作业标准 / 作业内容 / 学生提交」业务目录，安全、快捷。

### 10. 平台运营可配置
- 通过**数据库动态配置**维护排课规则、订单过期时间、业务开关等易变参数，改动**无需发版重启**即可生效。

## 五、关键业务亮点

- **零人工权限清单**：接口权限随代码注解自动同步，新增接口即纳入权限体系。
- **排课不再靠手推**：规则化自动生成课表，节假日、自习日自动规避，支持临时加课后联动重排。
- **教师档期零冲突**：按阶段排课时自动排除同时间段已授课教师。
- **考试全流程线上化**：从组卷、发布、在线作答到自动交卷、批改公布，一条龙闭环。
- **核心能力解耦沉淀**：日志链路追踪（MDC + requestId）、接口签名与防重放、统一脱敏日志等平台级能力为多业务模块复用。

## 六、技术栈

| 层面 | 技术选型 |
| --- | --- |
| 语言 / 框架 | Java · Spring Boot 3 |
| ORM | MyBatis-Plus |

| 参数校验 | JSR 303 + 自定义枚举状态校验 |
| Excel | EasyExcel（流式分批导入） |
| 日志 | Logback + MDC 全链路追踪、敏感字段脱敏 |

## 七、环境要求与快速开始

- **运行时**：JDK 17+、MySQL、Redis、RocketMQ
- **第三方依赖**：阿里云 OSS、支付宝开放平台（沙箱或正式）、节假日接口
- **配置入口**：`application.yml`（数据库、Redis、OSS、支付密钥、日志路径、权限同步与会话等开关）

> 详细的环境变量与开关说明可参考各模块配置类，启动前请确认相关中间件与第三方服务可用。
